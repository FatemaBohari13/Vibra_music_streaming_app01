# 🎵 Vibra – Music App

## 📌 Project Overview

Vibra is a modern and responsive Music App interface designed to provide users with an engaging and interactive music discovery experience. The application was developed using HTML, CSS, and JavaScript.

The objective of this project was to design and implement a visually appealing music application with multiple screens, intuitive navigation, interactive music player controls, search functionality, and a personal music library.

The app demonstrates modern UI design, responsive layouts, DOM manipulation, dynamic search, and interactive user interface elements.

## 🚀 Key Features

* Welcome, Login, and Signup screens
* Personalized home screen with curated playlists
* Search songs and artists dynamically
* Browse music by mood including Pop, Rock, Lo-fi, Dance, Chill, and Romantic
* Popular artists section
* Interactive music player interface
* Play and pause controls
* Previous, next, shuffle, and repeat controls
* Music progress and volume sliders
* Add and remove songs from favorites
* Personal library with favorite tracks, saved songs, playlists, and downloads
* Recently added songs section
* Bottom navigation for Home, Search, Favorites, and Library
* Toast notifications for user interactions
* Modern dark theme with purple and pink gradient design
* Responsive mobile-focused layout

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox, Grid, Gradients, Transitions & Responsive Design)
* JavaScript (DOM Manipulation, Event Handling, Dynamic Search & UI Interactions)
